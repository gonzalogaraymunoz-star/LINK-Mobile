# LINK Mobile Intelligence

LINK Mobile turns Mobile Next into a transversal execution capability for the LINK ecosystem.

It is not a testing product. Its role is to let a LINK agent use mobile interfaces as an intelligence surface when an API, MCP, web endpoint, or other structured connector is unavailable or insufficient.

## Intelligence loop
PERCEIVE -> INTERPRET -> DECIDE -> ACT -> OBSERVE -> REMEMBER -> REUSE

The upstream Mobile Next tools remain the device-control substrate. LINK adds mission context, policy, observations, evidence, memory contracts and transport selection.

## Transport
- local: simulator/emulator or physical device attached to a host.
- cloud: remote device provider supported by Mobile Next.
- auto: LINK chooses an available compatible target.

The reasoning layer must not depend on a particular Mac or phone.
